# UI/UX 가이드

작성: 🎨 UI/UX 디자인 에이전트

## 화면 구조 (단일 페이지)
1. 헤더: 서비스명, 샘플 파일 다운로드 링크
2. 업로드 존: 드래그앤드롭 또는 클릭, 허용 형식/용량 안내
3. 요약 카드: 라인 수 · 주문 수 · 오류/경고 · 공급가 · 부가세 · 합계
4. 상태 분포: 배송 상태별 배지
5. 탭: 주문 목록 / 검수 이슈 (이슈는 ERROR → WARN → INFO 순)
6. 내보내기 버튼: WMS CSV · JSON · 리포트 XLSX

## 디자인 시스템
- 색: 배경 `#f6f7fb`, 주색 `#4f46e5`, 오류 `#dc2626`, 경고 `#d97706`, 정보 `#2563eb`, 성공 `#16a34a`
- 상태 배지는 색 + 한글 라벨을 함께 표기 (색에만 의존하지 않음)
- 폰트: 시스템 한글 폰트 스택, 본문 14px, 테이블 13px
- 모바일(<720px)에서 카드 2열, 테이블 가로 스크롤
- 서버 응답 문자열은 `textContent` 로만 렌더링 (XSS 방지)
