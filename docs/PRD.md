# PRD — 부팡 물류 및 주문 처리 자동화 봇

작성: 💡 Ideation 에이전트 · 승인: 🧐 Supervisor / 👑 CEO

## 1. 목적
엑셀(.xlsx)/CSV 형태의 **패킹리스트·주문 데이터**를 업로드하면 사람이 수작업으로 하던
품목 검수, 단가 계산, 배송 상태 분류를 자동 수행하고 **물류 DB(WMS) 연동 포맷**으로 변환한다.

## 2. 사용자
- 물류 담당자: 입고/출고 데이터를 검수하고 이상 건을 빠르게 찾아야 함
- 주문 담당자: 주문별 금액·배송 상태를 확인하고 DB에 일괄 등록해야 함

## 3. 기능 요구사항
| ID | 기능 | 수용 기준 |
|----|------|-----------|
| F1 | 파일 업로드 | .xlsx/.csv, 최대 5MB, 최대 20,000행. 한글/영문 헤더 별칭 자동 인식 |
| F2 | 품목별 검수 | 필수값 누락, 수량/단가 형식 오류, 중복 라인, 입고 부족/초과, 전화번호 형식, 상태·운송장 불일치를 이슈(ERROR/WARN/INFO)로 보고 |
| F3 | 단가 계산 | 라인별 공급가·부가세(10%)·합계, 할인율 지원, 원 단위 반올림(HALF_UP), 주문별 합계와 배송비(설정 가능) |
| F4 | 배송 상태 분류 | 라인/주문을 READY, SHIPPING, DELIVERED, PARTIAL, BACKORDER, INSPECT_PENDING, HOLD, CANCELLED, RETURNED 로 분류 |
| F5 | 물류 DB 포맷 변환 | WMS용 CSV(고정 컬럼), JSON(schema_version 포함), 검수 리포트 XLSX 다운로드 |
| F6 | 인터페이스 | 웹 UI(드래그앤드롭), REST API, CLI |

## 4. 비기능 요구사항
- 보안: 업로드 크기/행 제한, 확장자 검증, 엑셀 수식 인젝션 방어, 서버에 파일 저장 안 함(무상태)
- 정확성: 금액은 `Decimal` 사용(부동소수점 금지)
- 이식성: Docker 단일 이미지, Nginx 리버스 프록시 예시 제공

## 5. 가정 (사용자 확인 필요 시 설정으로 변경 가능)
- 단가는 **VAT 별도** 기준 (`BOOPANG_PRICE_INCLUDES_VAT=true` 로 변경)
- 청구 수량은 **검수 수량(min(입고, 주문))**, 미검수면 주문 수량
- 배송비: 주문 합계 50,000원 미만 시 3,000원 (`BOOPANG_FREE_SHIPPING_THRESHOLD`, `BOOPANG_SHIPPING_FEE`)
- 할인율: 1 초과 값은 퍼센트(10 → 10%), 0~1은 비율(0.1 → 10%), `10%` 문자열 지원

## 6. 범위 제외
실제 WMS DB 직접 접속, 사용자 인증, 이력 저장 (후속 과제)
